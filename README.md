# Ambitious Digital Studios

Build a premium, highly animated, modern digital agency website for a small but ambitious team of 2–4 web developers and digital marketing professionals based in Nashik, Maharashtra, India.

IMPORTANT:
This is our own agency website.
The purpose of this website is to build trust with potential business clients such as hotels, restaurants, resorts, washing centers, local businesses, startups and established companies.

The agency name is NOT finalized yet.

Use a temporary brand name:
"NEXORA STUDIO"

Make the brand name, logo text, tagline and all brand references easy to replace later.

==================================================
CORE GOAL

The website should immediately communicate:

We are a professional technology team

We build premium websites

We create modern digital experiences

We help businesses grow online

We understand branding and digital marketing

We are a small team but highly capable

We work closely with clients

We create custom websites instead of cheap templates

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
